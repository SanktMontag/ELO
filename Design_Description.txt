Design Description: Contextual Elo Rating System

Overview

This system extends the classic Elo rating algorithm for use in small-division football/soccer leagues (6-8 teams per division). It addresses three limitations of standard Elo:

- No tie handling → Solved with three-outcome scoring (W=1.0, D=0.5, L=0.0)

- No margin-of-victory awareness → Solved with historically-calibrated goal difference multipliers

- No momentum/form signal → Solved with 5-game exponential decay form weighting

The system also serves as a prediction engine, generating Win/Draw/Loss probabilities and most-likely scorelines for upcoming matches.

Core Formula

The rating update for each team after a match:

R_new = R_old + K × G × (S - E)

Where:

- K = Dynamic K-factor (elevated during provisional period)

- G = Contextual goal difference multiplier (from historical z-score)

- S = Actual score (1.0 / 0.5 / 0.0)

- E = Expected score from logistic function: 1 / (1 + 10^(-Δ/400))

Component Design

1. Tie Handling

Standard three-outcome scoring inherited from chess Elo:

- Win = 1.0, Draw = 0.5, Loss = 0.0

A draw against an equally-rated opponent produces zero rating change (S=0.5, E=0.5, so S-E=0). A draw against a stronger opponent produces a small gain (S=0.5 > E<0.5).

2. Contextual Goal Difference Multiplier

The key innovation. Instead of a generic ln(GD+1) multiplier, the system asks: "How surprising was this goal difference given the Elo gap?"

How it works:

- Historical results are binned by Elo delta (50-point increments)

- For each bin, the mean and standard deviation of goal differences are calculated

- When a match occurs, the actual GD is compared to the expected GD for that Elo bin

- A z-score is computed: z = (actual_GD - expected_GD) / std_GD

- The z-score is mapped to a multiplier: G = 1.0 + 0.4 × z, clamped to [0.5, 2.0]

Effect:

- A 3-0 win by a heavy favourite → low z-score → G ≈ 1.0-1.2 (modest reward)

- A 3-0 win by an underdog → high z-score → G ≈ 1.8-2.0 (large reward)

- A 1-0 loss by a heavy favourite → negative z-score → G ≈ 0.5-0.7 (amplified penalty)

Fallback: Before sufficient historical data exists (< 50 matches), the system uses max(1.0, ln(|GD| + 1)) as a generic multiplier.

3. Form Weighting (5-Game Window)

Form captures short-term momentum that Elo (a long-term measure) may lag behind.

Design choice: Elo-adjusted form, not raw form.

Raw form (W/D/L record) is misleading because it ignores opponent strength. Instead, form is measured as cumulative over/under-performance vs Elo expectations:

form = Σ (decay^i × (S_i - E_i)) / Σ decay^i

Where i=0 is the most recent match and decay=0.80.

Form is used for PREDICTION only, not for rating updates. This keeps the Elo rating as a pure long-term strength measure while allowing predictions to incorporate short-term signals.

4. Provisional K-Factor

New teams (seeded by division) start with elevated K-factor for rapid convergence:

K_effective = K_base × (2.5 - 1.5 × progress)

Where progress = games_played / provisional_threshold (linear from 0 to 1).

This means:

- Game 1: K = 80 (2.5× base)

- Game 10: K = 56 (1.75× base)

- Game 20+: K = 32 (1.0× base)

5. Zero-Sum Constraint

The GD multiplier is computed once per match from team_a's perspective and applied identically to both teams' updates. Since (S_a - E_a) = -(S_b - E_b) and the same G is used, the system is exactly zero-sum when both teams have the same K-factor, and approximately zero-sum otherwise.

This prevents rating inflation that would occur if each team computed its own multiplier independently.

6. Prediction Engine

Predictions combine three signals:

- Elo-based expected score (long-term strength)

- Form adjustment (short-term momentum)

- Historical scoring model (Poisson λ parameters per Elo bin)

W/D/L decomposition:

- Draw probability is modeled as a Gaussian function of Elo delta: P(draw) = 0.26 × exp(-Δ²/(2×350²))

- This captures the empirical observation that draws are most common between evenly-matched teams

- Win/Loss probabilities are derived from the adjusted expected score and draw rate

Scoreline prediction:

- Goals for each team are modeled as independent Poisson processes

- λ parameters come from the historical scoring model (or linear fallback)

- A probability matrix is generated for all scorelines 0-0 through 6-6

- Top 5 most likely scorelines are returned

7. Seasonal Reset

Between seasons, ratings are regressed toward the division mean:

R_new = R_old + regression_factor × (division_mean - R_old)

With regression_factor = 0.25, this pulls outliers back by 25% — enough to account for roster changes without erasing earned rating. Form history is cleared entirely (new season = fresh start).

Validation Approach

Brier Score

Primary metric for prediction quality. Measures calibration + discrimination.

- 0.000 = perfect predictions

- 0.667 = equivalent to always guessing 33/33/33

- Target: < 0.62 for a well-calibrated system with sufficient history

Calibration Plot

For each predicted win probability bin (e.g., 20-30%, 30-40%), check that actual win rates match. Well-calibrated = predicted 40% → actual ~40%.

Spearman Rank Correlation

Measures whether the system correctly orders teams by strength. Target: ρ > 0.85 after 2+ seasons.

Inflation Check

Total Elo across all teams should remain approximately constant over time. Drift > 2% indicates a zero-sum violation.

Simulation Results (5 Seasons, 14 Teams, 450 Matches)

- Rating accuracy: Mean Absolute Error = 59.4 Elo points

- Inflation: +0.1% (effectively zero)

- Brier Score: 0.622 (best season) — 6.6% better than naive baseline

- Calibration: All bins within 10% of predicted (✓)

- Rank correlation: ρ = 0.881 (p < 0.0001)

- Division separation: Clean — no overlap between Premier and Championship ratings

- Form impact: Matches with significant form had better Brier (0.630 vs 0.664)

Known Limitations

- Poisson independence assumption: Goals for/against are modeled independently, which slightly underestimates draw probability. A bivariate Poisson or copula correction can address this.

- Small sample bins: With 6-8 teams, some Elo delta bins may have very few data points. The system handles this with fallback interpolation, but predictions for extreme Elo gaps may be less reliable.

- No home/away modeling: The current system treats all matches as neutral venue. Adding a home advantage constant (+50-80 Elo for home team when calculating E) is a straightforward extension.

- Static true strength assumption: The simulation assumes teams have fixed underlying strength. In reality, squads change — the seasonal reset partially addresses this.

- Form as noise vs signal: In very small samples (early season), form may be noise rather than signal. The form_weight parameter should be validated with Brier Score on holdout data.

Extension Points

- Home/away split: Add venue parameter to process_match and predict; shift E_a by a home advantage constant

- Head-to-head: For frequent matchups in small divisions, add H2H adjustment as described in the design discussion

- Tournament mode: Reduce form_weight and increase K_base for knockout competitions

- Multi-league: Share historical model across divisions but maintain separate rating pools

- Real-time API: Wrap predict() in a REST endpoint for pre-match prediction service
